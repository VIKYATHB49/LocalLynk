# 🛍️ LocalLynk - Smart Local Delivery UX Case Study

LocalLynk is a UI/UX design solution crafted as part of a UI/UX Hackathon. It focuses on streamlining hyperlocal product delivery by allowing users to choose between multiple delivery methods—**Express**, **Normal**, and **Slow**—with different sellers based on cost and speed. The project aims to enhance user experience through intuitive design, transparency, and efficiency.

---

## 🚀 Project Objective

To design a platform that:
- Connects users to local sellers.
- Offers delivery flexibility (Express, Normal, Slow).
- Enables informed product selection based on pricing, delivery cost, and ETA.
- Enhances transparency and convenience in local e-commerce.

---

## 🔍 UX Design Process

### 1. 🧠 User Research
- Conducted surveys and interviews with target users (students, PG/hostel residents, local shop owners).
- Identified key pain points: lack of real-time product availability, inconsistent delivery updates, limited seller options.

### 2. 🔄 User Flow Diagram
- Designed a comprehensive user flow illustrating how a user navigates from product search to checkout and order tracking.
- Covered alternate scenarios for switching sellers, changing delivery speed, and handling out-of-stock issues.

### 3. 👥 Empathy Mapping
- Built empathy maps to understand user needs, thoughts, pains, and gains.
- Helped define user personas for better UI decisions.

### 4. 🧩 Wireframes & Ideation
- Sketched low-fidelity wireframes for key screens: Home, Product List, Seller Comparison, Product Details, and Order Tracking.
- Iterated based on peer and mentor feedback during the hackathon.

### 5. 🎨 High-Fidelity Design
- Created pixel-perfect high-fidelity screens using Figma.
- Applied a clean, accessible color palette with strong visual hierarchy for smooth navigation.

### 6. 🔄 Prototyping & Interactions
- Developed an interactive prototype in Figma showcasing:
  - Product browsing.
  - Delivery method selection.
  - Seller comparison and ratings.
  - Live stock and order tracking flow.

---

## 🧩 Key Features

- 📍 **Seller Details & Location**: View complete seller profiles including their location on the map.
- ⭐ **Ratings & Reviews**: User-submitted product feedback for quality assurance.
- 📦 **Live Stock Updates**: Real-time inventory visibility.
- 🚚 **Live Order Tracking**: Track your order post-purchase based on the selected delivery mode.
- ⏱ **Delivery Options**: Choose between Express (fast), Normal, or Slow (eco-friendly) delivery methods, with dynamic pricing and ETA.
